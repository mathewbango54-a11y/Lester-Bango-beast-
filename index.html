How V30 works

1. Loads real football fixtures from a live scoreboard source.
2. Searches recent completed matches for the same teams.
3. Calculates recent win/draw/loss form.
4. Calculates attacking and defensive strength from recent results.
5. Combines home advantage + form + attack + defence.
6. Converts the result into 1X2 percentages.
7. Produces a confidence level.

Percentages are model estimates, not guaranteed outcomes.
